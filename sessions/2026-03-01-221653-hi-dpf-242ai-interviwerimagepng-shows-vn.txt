● What is a VHD?

  A VHD (Virtual Hard Disk) is a single file on your C: drive that acts as a
  fake hard drive for WSL2/Docker. Docker stores everything inside it — all
  images, containers, volumes, build cache. Think of it as a box that holds all
  of Docker's data.

  ---
  Can you delete it?

  Yes, but it will wipe all Docker images and volumes. You'll need to rebuild
  everything with docker compose up --build.

  Since Docker is stuck anyway, the cleanest solution is to use Docker Desktop's
   built-in reset instead of manually deleting the file:

  Option 1 — Reset Docker Desktop (recommended):
  1. Find Docker Desktop in Start menu → right-click → Run as administrator
  2. If it opens: Settings → Troubleshoot → Reset to factory defaults
  3. If it won't open: go to C:\Users\parep\AppData\Local\Docker and delete the
  wsl folder entirely
  4. Reinstall Docker Desktop if needed

  Option 2 — Manual delete (if Docker won't open at all):

  Open PowerShell as Admin:
  wsl --shutdown
  Remove-Item "C:\Users\parep\AppData\Local\Docker\wsl" -Recurse -Force
  Then start Docker Desktop — it will recreate the VHD fresh and start normally.
