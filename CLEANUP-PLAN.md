## PHASE 2 — Fix dependency inconsistencies (requires rebuild)

### TTS/requirements.txt
```
# Remove this line:
nats-py>=2.6.0
```
**Why:** nats-py was removed from pyproject.toml and uv.lock weeks ago.
The requirements.txt is stale and confusing. TTS uses uv/pyproject.toml —
requirements.txt should either be removed or kept in sync.

**Decision needed:** Does TTS even use requirements.txt? Or just pyproject.toml + uv.lock?
→ If Docker installs via uv: keep pyproject.toml, delete requirements.txt
→ If Docker installs via pip -r: remove nats-py, keep requirements.txt in sync

### .env.example files
Each service has its own `.env.example`. They are out of sync with the root `.env`.
- `Main-Agent/.env.example` — has `ANTHROPIC_MODEL=claude-sonnet-4` (wrong model ID)
- `TTS/.env.example` — still has `NATS_URI=` field
- Root `.env.example` — needs `ANTHROPIC_API_KEY=` added

**Action:** Update all `.env.example` files to match the root `.env` structure.
Root `.env` remains the single source of truth for Docker.
